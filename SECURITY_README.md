# VPN Server - Enhanced Security Configuration

## 📋 Обзор

Это улучшенная конфигурация безопасности для VPN сервера на базе 3x-ui и Telegram бота. Проект включает комплексные меры безопасности, мониторинг и автоматизацию.

## 🚀 Новые возможности безопасности

- ✅ **Автоматическая настройка безопасности сервера**
- ✅ **Маскировка сервера под техническое обслуживание**
- ✅ **Мониторинг безопасности в реальном времени**
- ✅ **Автоматическое резервное копирование**
- ✅ **Защита от DDoS и брутфорс атак**
- ✅ **Настройка 3x-ui с Reality протоколом**
- ✅ **SSL/TLS шифрование для всех сервисов**

## 🔥 Быстрый старт

### 1. Базовая настройка безопасности
```bash
# Скопируйте репозиторий
git clone <repository-url>
cd Fozzy-wpn

# Запустите быструю настройку
sudo chmod +x scripts/quick_setup.sh
sudo ./scripts/quick_setup.sh
```

### 2. Развертывание проекта
```bash
# Переключитесь на пользователя deploy
su - deploy

# Клонируйте и настройте проект
git clone <repository-url>
cd Fozzy-wpn

# Настройте переменные окружения
cp .env.example .env
nano .env

# Запустите с улучшенной безопасностью
docker-compose -f docker-compose.security.yml up -d
```

### 3. Настройка SSL и домена
```bash
# Получите SSL сертификат
sudo certbot --nginx -d your-domain.com

# Настройте автообновление
echo "0 12 * * * /usr/bin/certbot renew --quiet" | sudo crontab -
```

## 📊 Мониторинг

### Запуск мониторинга
```bash
# Сделайте скрипты исполняемыми
chmod +x scripts/monitor.sh scripts/backup.sh

# Настройте cron для автоматического мониторинга
crontab -e
# Добавьте:
*/5 * * * * /home/deploy/Fozzy-wpn/scripts/monitor.sh check
0 */6 * * * /home/deploy/Fozzy-wpn/scripts/monitor.sh report
0 2 * * * /home/deploy/Fozzy-wpn/scripts/backup.sh full
```

### Что проверяет мониторинг
- 🖥️ **Системные ресурсы**: CPU, память, диск
- 🔌 **Сетевые соединения**: количество и подозрительная активность
- 🔐 **Безопасность**: Fail2ban, firewall, попытки взлома
- 🐳 **Docker контейнеры**: статус и производительность
- 🌐 **3x-ui API**: доступность и ответ

## 🎭 Маскировка сервера

Сервер автоматически маскируется под сайт технического обслуживания:

- **Порт 80/443**: Показывает страницу техработ
- **Порт 443 (VLESS)**: Работает как обычный HTTPS
- **Порт 2053**: Панель 3x-ui (только для админа)

## 🔒 Ключевые настройки безопасности

### Firewall (UFW)
```bash
# Открытые порты:
22/tcp   # SSH (только для администратора)
80/tcp   # HTTP для страницы-заглушки
443/tcp  # HTTPS для VLESS/VMess
443/udp  # QUIC для улучшения производительности
2053/tcp # 3x-ui панель
```

### SSH Безопасность
- ❌ Запрет root входа
- ❌ Запрет аутентификации по паролю
- ✅ Только SSH ключи
- ✅ Измененный порт (опционально)

### Docker Безопасность
- ✅ Изолированные сети
- ✅ Ограниченные права контейнеров
- ✅ Health checks для всех сервисов
- ✅ Только локальные порты для базы данных
