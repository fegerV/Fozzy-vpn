## 🔒 Настройки безопасности сервера

### 🚀 Быстрый старт (5 минут)

```bash
# 1. Клонируйте репозиторий
git clone <repository-url>
cd Fozzy-wpn

# 2. Запустите автоматическую настройку
sudo chmod +x scripts/quick_setup.sh
sudo ./scripts/quick_setup.sh

# 3. Переключитесь на пользователя deploy
su - deploy

# 4. Настройте проект
cp .env.example .env
nano .env  # Введите ваши данные

# 5. Запустите VPN сервис
docker-compose -f docker-compose.security.yml up -d
```

### 🛡️ Комплексная безопасность

**Автоматически настраивается:**
- ✅ **Firewall (UFW)** с правильными портами
- ✅ **Fail2Ban** защита от брутфорс атак  
- ✅ **SSH безопасность** (запрет root, только ключи)
- ✅ **Автоматические обновления** системы
- ✅ **Системные ограничения** защиты от DDoS
- ✅ **Логирование** всех событий безопасности
- ✅ **Пользователь deploy** для безопасного деплоя

**Порты безопасности:**
```bash
22/tcp   # SSH (только для администратора)
80/tcp   # HTTP для страницы-заглушки
443/tcp  # HTTPS для VPN протоколов  
443/udp  # QUIC для производительности
2053/tcp # 3x-ui панель
```

### 📊 Мониторинг безопасности

**Автоматическая проверка каждые 5 минут:**
- 🖥️ **CPU > 90%** → Критический алерт
- 🧠 **Память > 85%** → Предупреждение
- 💾 **Диск < 10%** → Критический алерт  
- 🔌 **Соединения > 1000** → Внимание
- 🚪 **Неудачных входов > 10/час** → Подозрительно

**Команды мониторинга:**
```bash
./scripts/monitor.sh check     # Полная проверка
./scripts/monitor.sh report    # Генерация отчета
./scripts/monitor.sh security  # Проверка безопасности
```

## ⚙️ Настройка 3x-ui

### 🔧 Установка и базовая настройка

```bash
# Установка 3x-ui
bash <(curl -Ls https://raw.githubusercontent.com/vaxilu/x-ui/master/install.sh)

# Доступ к панели
https://your-server.com:2053
Логин: admin
Пароль: ваш_сложный_пароль
```

### 🌟 Рекомендуемые протоколы

#### 1. VLESS + Reality (Основной)
**Преимущества:**
- 🔐 Максимальная маскировка под обычный HTTPS
- ⚡ Высокая производительность
- 🛡️ Устойчивость к блокировкам
- 🔍 Невидимость для DPI систем

**Настройка:**
```json
{
  "protocol": "vless",
  "network": "tcp", 
  "tls": "tls",
  "flow": "xtls-rprx-vision",
  "reality": {
    "enabled": true,
    "dest": "www.google.com:443",
    "serverNames": ["www.google.com"],
    "privateKey": "ВАШ_СЕКРЕТНЫЙ_КЛЮЧ",
    "shortIds": ["", "6ba85179e30d4fc2"]
  }
}
```

#### 2. VMess + WebSocket (Резервный)
**Преимущества:**
- 🔄 Совместимость со всеми клиентами
- 🌐 Маскировка под веб-трафик
- 📡 Поддержка CDN
- ⚙️ Гибкая настройка

**Настройка:**
```json
{
  "protocol": "vmess",
  "network": "ws",
  "tls": "tls", 
  "path": "/vmess",
  "headers": {
    "Host": "your-domain.com"
  }
}
```

### 🔒 Безопасность 3x-ui

**Обязательные настройки:**
1. **Измените порт панели** с 2053 на другой
2. **Установите сложный пароль** (16+ символов)
3. **Включите SSL/TLS** для панели
4. **Настройте двухфакторную аутентификацию**
5. **Установите лимиты клиентов**
6. **Включите логирование**

**Рекомендуемые лимиты:**
```yaml
Лимит данных: 100GB (по умолчанию)
Лимит IP: 1 (для безопасности)
Время жизни: по тарифу
Автоочистка: каждые 24 часа
```

## ⚠️ Критичные настройки

### 🎯 Reality протокол (ВАЖНО!)

**Что это:** Маскировка VPN трафика под обычные HTTPS запросы к популярным сайтам.

**Настройка:**
```bash
# В панели 3x-ui:
1. Выберите VLESS + Reality
2. Destination: www.google.com:443
3. Server Names: ["www.google.com"]
4. Сгенерируйте ключи
5. Сохраните приватный ключ
```

**Результат:** Ваш VPN трафик выглядит как обычные запросы к Google.

### 🔐 Ограничения клиентов

**Безопасные настройки:**
```json
{
  "limitIp": 1,                    // Только один IP на клиента
  "totalGB": 107374182400,         // 100GB в байтах
  "expiryTime": 1703952000,        // Timestamp истечения
  "enable": true,                  // Активен
  "email": "user_123_456"          // Уникальный email
}
```

### 🖥️ Системные параметры

**Защита от DDoS:**
```bash
net.ipv4.tcp_syncookies = 1           # Защита от SYN flood
net.ipv4.tcp_max_syn_backlog = 2048    # Увеличение очереди
net.ipv4.conf.all.rp_filter = 1        # Защита от IP spoofing
net.ipv4.tcp_congestion_control = bbr   # Алгоритм BBR
```

## 🎭 Маскировка сервера

### 🌐 Что такое страница-заглушка

**Цели:**
- 🎭 Скрыть VPN от сканеров и анализаторов
- 🔐 Защитить от автоматических блокировок
- 🌐 Выглядеть как обычный веб-сайт
- 📊 Показывать "технические работы"

### ⚙️ Как это работает

```
┌─────────────┐    ┌──────────────┐    ┌─────────────────┐
│  Пользователь  │───▶│    Nginx     │───▶│ Страница заглушка│
│   (Браузер)   │    │ (80/443)     │    │  "Техработы"    │
└─────────────┘    └──────────────┘    └─────────────────┘

┌─────────────┐    ┌──────────────┐    ┌─────────────────┐
│ VPN клиент   │───▶│   3x-ui      │───▶│   VPN туннель   │
│              │    │ (443/TCP)    │    │                 │
└─────────────┘    └──────────────┘    └─────────────────┘

┌─────────────┐    ┌──────────────┐    ┌─────────────────┐
│ Администратор│───▶│   3x-ui      │───▶│ Панель управления│
│              │    │ (2053)       │    │                 │
└─────────────┘    └──────────────┘    └─────────────────┘
```

## 🚨 Действия при проблемах

### 🆘 При подозрении на взлом:

1. **Немедленно заблокируйте** подозрительные IP:
   ```bash
   sudo ufw deny from SUSPICIOUS_IP
   ```

2. **Измените все пароли** и SSH ключи:
   ```bash
   sudo passwd deploy
   # Сгенерируйте новые SSH ключи
   ```

3. **Проверьте логи** на признаки компрометации:
   ```bash
   sudo grep "Failed password" /var/log/auth.log | tail -50
   sudo journalctl -f -u ssh
   ```

4. **Восстановитесь** из чистого бэкапа:
   ```bash
   ./scripts/backup.sh restore LATEST_CLEAN_BACKUP
   ```

5. **Обновите все компоненты** системы:
   ```bash
   sudo apt update && sudo apt upgrade -y
   docker-compose pull && docker-compose up -d
   ```

### 🔧 Проблемы с сервисами:

**Бот не запускается:**
```bash
# Проверка логов
docker-compose logs bot

# Проверка переменных окружения
docker-compose exec bot printenv

# Проверка токена бота
curl -X GET "https://api.telegram.org/bot$TOKEN/getMe"
```

**Проблемы с 3x-ui:**
```bash
# Тест API
python manage.py test-xui

# Проверка статуса
x-ui status

# Перезапуск сервиса
sudo systemctl restart x-ui
```

**Проблемы с базой данных:**
```bash
# Проверка подключения

# Применение миграций
```
