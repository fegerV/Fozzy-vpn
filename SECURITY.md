## 🚀 Начальная настройка безопасности

### 1. Запуск скрипта безопасности

```bash
# Скачайте и запустите скрипт настройки безопасности
sudo chmod +x scripts/setup_security.sh
sudo ./scripts/setup_security.sh
```

**Что делает скрипт:**
- ✅ Обновляет систему до последней версии
- ✅ Настраивает SSH безопасность (запрет root входа)
- ✅ Настраивает Firewall (UFW) с необходимыми портами
- ✅ Устанавливает Fail2Ban для защиты от брутфорса
- ✅ Настраивает автоматические обновления
- ✅ Оптимизирует системные параметры
- ✅ Создает пользователя deploy для деплоя
- ✅ Устанавливает Docker и Docker Compose

### 2. Настройка SSH ключей

```bash
# Переключитесь на пользователя deploy
su - deploy

# Создайте SSH ключи (если еще не созданы)
ssh-keygen -t rsa -b 4096 -C "deploy@vpn-server"

# Добавьте публичный ключ в authorized_keys
cat ~/.ssh/id_rsa.pub >> ~/.ssh/authorized_keys
chmod 600 ~/.ssh/authorized_keys
```

### 3. Настройка Firewall

```bash
# Проверьте статус firewall
sudo ufw status

# Разрешите необходимые порты
sudo ufw allow 22/tcp      # SSH
sudo ufw allow 80/tcp       # HTTP для заглушки
sudo ufw allow 443/tcp      # HTTPS
sudo ufw allow 443/udp      # QUIC/UDP
sudo ufw allow 2053/tcp     # 3x-ui панель
```

## 🔧 Настройка 3x-ui протоколов

### 1. Рекомендуемые протоколы

#### VLESS (основной протокол)
```json
{
  "protocol": "vless",
  "network": "tcp",
  "tls": "tls",
  "flow": "xtls-rprx-vision",
  "reality": {
    "enabled": true,
    "dest": "www.google.com:443",
    "serverNames": ["www.google.com"],
    "privateKey": "YOUR_PRIVATE_KEY",
    "shortIds": ["", "6ba85179e30d4fc2"]
  }
}
```

#### VMess (резервный протокол)
```json
{
  "protocol": "vmess",
  "network": "ws",
  "tls": "tls",
  "path": "/vmess",
  "headers": {
    "Host": "your-domain.com"
  }
}
```

### 2. Настройка Reality

Reality обеспечивает максимальную маскировку трафика:

```bash
# Сгенерируйте ключи Reality
x-ui reality

# Создайте Reality inbound
x-ui add
# Выберите VLESS + Reality + TCP
# Укажите destination: www.google.com:443
# Сгенерируйте и сохраните ключи
```

### 3. Оптимальные настройки

```yaml
# Порты:
- VLESS Reality: 443 (TCP/UDP)
- VMess WebSocket: 443 (TCP)
- 3x-ui панель: 2053 (TCP)
- Страница-заглушка: 80/443 (TCP)

# Безопасность:
- Включите TLS для всех протоколов
- Используйте Reality для маскировки
- Ограничьте количество подключений на клиента
- Установите лимиты трафика
- Настройте автоматическую очистку
```

## 🎭 Маскировка сервера

### 1. Установка Nginx и страницы-заглушки

```bash
# Создайте директорию для веб-сервера
sudo mkdir -p /var/www/html
sudo cp configs/stub-page.html /var/www/html/index.html

# Установите Nginx
sudo apt install nginx

# Скопируйте конфигурацию
sudo cp configs/nginx-stub.conf /etc/nginx/sites-available/default
sudo nginx -t && sudo systemctl restart nginx
```

### 2. Настройка SSL сертификата

```bash
# Установите Certbot
sudo apt install certbot python3-certbot-nginx

# Получите SSL сертификат
sudo certbot --nginx -d your-domain.com

# Настройте автообновление
sudo crontab -e
# Добавьте строку:
0 12 * * * /usr/bin/certbot renew --quiet
```

### 3. Результат маскировки

- **Порт 80/443**: Показывает страницу технических работ
- **Порт 443 (VLESS)**: Работает как обычный HTTPS трафик
- **Порт 2053**: Панель управления 3x-ui (только для администратора)
- **Все остальные порты**: Заблокированы firewall

## 📊 Мониторинг безопасности

### 1. Настройка мониторинга

```bash
# Сделайте скрипт мониторинга исполняемым
chmod +x scripts/monitor.sh

# Добавьте в cron для регулярных проверок
crontab -e
# Добавьте строки:
*/5 * * * * /home/deploy/Fozzy-wpn/scripts/monitor.sh check
0 */6 * * * /home/deploy/Fozzy-wpn/scripts/monitor.sh report
```

### 2. Что проверяет мониторинг

- **Системные ресурсы**: CPU, память, дисковое пространство
- **Статус сервисов**: Docker контейнеры, 3x-ui, Nginx
- **Безопасность**: Fail2ban, firewall, попытки взлома
- **Сеть**: Количество соединений, подозрительная активность
- **3x-ui API**: Доступность панели управления

### 3. Алерты

Мониторинг отправляет алерты при:
- ❌ Высокая загрузка CPU (>90%)
- ❌ Критическое использование памяти (>85%)
- ❌ Мало места на диске (<10%)
- ❌ Отключение сервисов
- ❌ Подозрительная активность

## 💾 Резервное копирование

### 1. Настройка автоматических бэкапов

```bash
# Сделайте скрипт бэкапа исполняемым
chmod +x scripts/backup.sh

# Настройте ежедневный бэкап в cron
crontab -e
# Добавьте строку:
0 2 * * * /home/deploy/Fozzy-wpn/scripts/backup.sh full
```

### 2. Что сохраняется

- ✅ Конфигурация 3x-ui
- ✅ База данных PostgreSQL
- ✅ Docker образы и volumes
- ✅ Файлы проекта
- ✅ Системные конфигурации

### 3. Управление бэкапами

```bash
# Создать полный бэкап
./scripts/backup.sh full

# Создать бэкап только конфигурации
./scripts/backup.sh config

# Посмотреть список бэкапов
./scripts/backup.sh list

# Восстановиться из бэкапа
./scripts/backup.sh restore /opt/vpn-server/backups/vpn-server-full-backup-20240101-020000.tar.gz
```

## 🚨 Реагирование на инциденты

### 1. Подозрительная активность

```bash
# Проверка последних входов
sudo last -n 20

# Проверка неудачных попыток входа
sudo grep "Failed password" /var/log/auth.log | tail -20

# Блокировка IP адреса
sudo ufw deny from SUSPICIOUS_IP
```

### 2. Проблемы с сервисами

```bash
# Перезапуск всех сервисов
docker-compose restart

# Проверка статуса контейнеров
docker ps -a

# Просмотр логов
docker-compose logs -f bot
```

### 3. Восстановление из бэкапа

```bash
# Остановка сервисов
docker-compose down

# Восстановление базы данных
./scripts/backup.sh restore LATEST_BACKUP

# Запуск сервисов
docker-compose up -d
```
